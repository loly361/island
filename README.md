# Island

«Динамический остров» для Windows: чёрная плашка сверху по центру экрана с часами и погодой. При наведении мыши она раскрывается в панель.

## Запуск

Готовая сборка лежит в папке `dist`. Установленная копия работает из `%LOCALAPPDATA%\Programs\Island`: её можно перенести куда угодно, автозапуск переписывает путь сам при каждом старте. Запустите `Island.exe`: значок появится в трее (правый нижний угол). Нужен .NET 9 Desktop Runtime.

Сборка из исходников:

```
dotnet build src\Island -c Release
dotnet test tests\Island.Tests
```

## Что умеет

| Вкладка | Возможности |
|---|---|
| Главная | плеер (то, что играет в Windows) и громкость, быстрые действия, ярлыки программ |
| Буфер | история копирования с поиском, клик вставляет, Shift+клик только копирует, закрепление, удаление |
| Уведомления | уведомления Windows приходят баннером на остров и копятся в списке (только в памяти, на диск не пишутся) |
| Заметки | вкладки-заметки; жирный, курсив, зачёркнутый, списки, задачи с галочками (`☐` → `☑`, клик по квадрату), сохраняются автоматически. Справа: таймер (5/10/15/25/45 минут или своё время, идёт даже при свёрнутом острове) и напоминания |
| Погода | сейчас, ближайшие 8 часов, 7 дней, ветер, влажность, осадки, восход и закат (Open-Meteo) |
| Управление | Wi-Fi, Bluetooth, тёмная тема, VPN (подключение Windows), блокировка, сон, перезагрузка и выключение (нужно нажать дважды) |
| Поиск | `Alt+Space` (если занято, `Ctrl+Alt+Space`): программы, файлы из индекса Windows, «Спросить ИИ» (claude.ai) и поиск в браузере |
| Настройки | город и координаты для погоды, адреса поиска и «Спросить ИИ», акцентный цвет (из обоев или один из четырёх), ссылки на файл настроек и папку с данными. Изменения сохраняются сразу, некорректное значение откатывается |

Быстрые действия: скриншот области, снимок всего экрана (оба копируются в буфер и сохраняются в `Изображения\Screenshots`), текст с экрана (OCR Windows, языки берутся из профиля), пипетка (цвет в HEX в буфер), чистый текст (убирает форматирование в буфере).

Напоминания пишутся обычной фразой: «позвонить маме завтра в 9», «таблетки каждый день в 23:00», «через 20 минут выключить плиту», «в пятницу в 18:30 созвон». Когда время придёт, остров покажет баннер и проиграет звук.

`Esc` закрывает панель. Значок канцелярской кнопки справа вверху закрепляет панель открытой.

## Уведомления Claude Code

Остров слушает `http://127.0.0.1:47831/notify` (только локальный компьютер). Запрос: `POST` с JSON `{"title": "...", "message": "..."}` и заголовком `X-Island-Token`. Токен генерируется при первом запуске и хранится в `settings.json` (поле `NotifyToken`). Без токена остров отвечает `401`, GET-запросы и запросы из браузера (с заголовком `Origin`) отклоняются. Тело длиннее 8 КБ отклоняется, даже если заголовок длины не указан.

Чтобы остров показывал «Claude Code ждёт ответа», добавьте хук в `~/.claude/settings.json` (путь к скрипту замените на свой). Скрипт сам читает токен из `%AppData%\Island\settings.json`, ничего копировать не нужно:

```json
{
  "hooks": {
    "Notification": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "powershell -NoProfile -ExecutionPolicy Bypass -File \"C:\\путь\\к\\Island\\tools\\claude-hook.ps1\""
          }
        ]
      }
    ]
  }
}
```

## Оформление

- Чистый чёрный остров с тонким контуром, карточки из полупрозрачного белого, крупные скругления, как в iOS.
- Акцентный цвет берётся из обоев: берётся самый яркий оттенок, при смене обоев цвет плавно меняется. Если обои серые, используется акцент Windows. Цвет можно зафиксировать во вкладке «Настройки».
- Свёрнутая плашка показывает обложку играющего трека (если она есть) и мини-кольцо таймера с отсчётом. Плашка растягивается под них.
- Остров раскрывается с лёгкой пружиной, вкладки переключаются скользящим индикатором, содержимое вкладки плавно выезжает. Кнопки слегка «вдавливаются» при нажатии.
- Погода: фон карточки зависит от условий (ясно, облачно, дождь, снег, гроза, ночь), иконки с градиентами, полосы недели окрашены по температуре.

## Данные и приватность

Всё хранится в `%AppData%\Island`: `settings.json`, `clipboard.dat` (история буфера, зашифрована средствами Windows для вашей учётной записи), `notes.json`, `error.log`. Незакреплённые записи буфера старше суток удаляются при запуске, закреплённые остаются. Старый `clipboard.json` с открытым текстом переносится в шифрованный файл при первом запуске и удаляется.

- Копии из менеджеров паролей, которые помечают данные как исключённые из истории, остров не записывает.
- Очистить историю можно кнопкой с корзиной на вкладке «Буфер»; закреплённое остаётся.
- Погода берётся с open-meteo.com. Город определяется один раз по IP через ipwho.is, координаты сохраняются в `settings.json`. Можно вписать свои `Latitude` и `Longitude`.
- В `settings.json` также меняются ссылки `SearchUrl` и `AskUrl`, порт `NotifyPort` и список ярлыков `Shortcuts`.

## Ограничения первой версии

- Остров показывается поверх полноэкранных окон так же, как обычное окно «поверх всех»; специального режима для игр нет.
- Запись экрана, QR-коды и поле команд не делались.
- Уведомления Windows не читаются, если программа лежит в папке с очень длинным путём (около 200 символов и больше): это ограничение Windows. Держите `Island.exe` в коротком пути, например в `Загрузки\Island`.
- VPN переключается только для подключений, добавленных в Параметры Windows. Сторонние VPN-клиенты (WireGuard, Cloudflare WARP и т. п.) плитка не видит.
- Город для погоды определяется по IP; если стоит VPN, он может быть чужим. Впишите свои `Latitude`, `Longitude` и `City` в `settings.json`.
- Остров рисуется на основном мониторе.
